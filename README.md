# OneSync Distribution Platform

A modern music distribution platform built with Webflow, featuring:

- 🎵 Global music distribution
- 🎧 Beat marketplace 
- 🤝 Industry networking forum
- 📊 Real-time analytics
- 💰 Royalty management
- 🎯 AI mastering and marketing services

## Live Demo
Visit: https://app.onesync.music

## Features
- Multi-video background hero section
- Smooth logo carousel
- Glassmorphism UI design
- Purple gradient branding
- Responsive design
- Artist showcase gallery

## Tech Stack
- HTML5/CSS3
- Webflow CMS
- Custom JavaScript animations
- Python HTTP server for deployment

## Deployment
Deployed on Heroku with automatic builds from the main branch.
